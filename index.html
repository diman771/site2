Вопросы и теория по CSS

Нажмите на интересующий вопрос, чтобы развернуть подробный ответ о принципах работы каскадных таблиц стилей.

Каскадность (Cascading) определяет то, как браузер разрешает конфликты, когда к одному и тому же HTML-элементу применяется несколько противоречащих друг другу правил стилей. Порядок применения зависит от происхождения стилей, специфичности селекторов и порядка их написания.

Основные селекторы в CSS различаются по специфичности:
  • Селекторы тегов (например, p, h1) — применяют стили ко всем элементам указанного типа.
  • Селекторы классов (например, .btn) — универсальные стили для элементов с заданным классом.
  • Селекторы идентификаторов (например, #header) — уникальные стили для строго одного элемента на странице.

Каждый элемент в CSS представляет собой прямоугольный бокс, состоящий из четырех областей (изнутри наружу):

1. Content (Содержимое) — текст или изображение.
2. Padding (Внутренние отступы) — пространство между текстом и рамкой.
3. Border (Граница) — рамка элемента.
4. Margin (Внешние отступы) — отступы от других элементов.

Специфичность — это «вес» правила, определяющий приоритет отображения. Наивысший вес у inline-стилей, затем идут ID (#id), классы и атрибуты (.class), а наименьший вес имеют теги.
